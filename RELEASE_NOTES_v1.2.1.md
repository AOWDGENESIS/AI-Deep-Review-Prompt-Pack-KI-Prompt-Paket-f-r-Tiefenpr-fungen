# Release Notes — v1.2.1

## Deutsch

Version 1.2.1 ist ein qualitätssicherndes Patch Release nach einer erneuten Tiefenprüfung des
vollständigen Release-Artefakts. Korrigiert wurden nicht mehr erreichbare oder unpräzise Referenzlinks:
NIST SSDF verweist nun auf die stabile NIST-Publikationsseite, OWASP API Security auf die aktuelle
Projektadresse, OWASP Java auf die gepflegte Cheat-Sheet-Serie sowie Groovy/Clojure auf aktuelle
Primärdokumentation. Die Korrekturen wurden in Master-Prompts und allen betroffenen Standalone-Dateien
synchronisiert.

Zusätzlich wurden die GitHub Issue Forms auf das gültige Issue-Form-Schema mit eindeutigen `id`-Feldern
korrigiert, der lokale Validator erweitert und eine optionale, sichere CODEOWNERS-Anleitung ergänzt.

## English

Version 1.2.1 is a quality-assurance patch release after a renewed deep review of the complete release
artifact. It corrects unreachable or imprecise reference links: NIST SSDF now points to the stable NIST
publication page, OWASP API Security to the current project address, OWASP Java to the maintained Cheat
Sheet Series, and Groovy/Clojure to current primary documentation. These corrections were synchronized
across the master prompts and every affected standalone file.

GitHub Issue Forms were also corrected to the valid Issue Form schema with unique `id` fields, the local
validator was expanded, and an optional, safe CODEOWNERS setup guide was added.
